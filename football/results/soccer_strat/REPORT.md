# soccer_strat：Polymarket 五大联赛足球市场策略研究报告

## 结论

数据范围：2,200 场 `analysis_ready` 比赛（2025-08 至 2026-11-03）、676 万笔 1X2 taker 成交，加上我补抓的 108 万笔 O/U 2.5 和 BTTS 成交。所有结果都按今天的 taker 费率计算：每次成交每股 0.05·p·(1−p)，所有时期一律适用。在这个口径下，**没有一条可执行的策略在 test 期站得住**。我一共试了约 1,400 个规则变体。只要有一个 train 期参数组合"赢"了，到 test 期就会消失或反号。

最像真信号的一条是"进球后，模型说价格还没追上，就买进球方 YES、买失球方 NO"。以成交里的价格跳变为时间锚时，train 和 test 都显著为正。但利润几乎全部来自 ESPN 时间比价格跳变晚 60 秒以上的进球，这类进球多半在等 VAR 复核。样本只含最终有效的进球。ESPN commentary 里还有 555 条被 VAR 取消的进球（270 条 goal overturned、285 条 VAR decision: no goal），同样的触发规则也会买进它们，但它们不在样本里。所以这份利润是幸存者偏差，等于用了未来信息。改成等官方比分确认后再入场，收益如下：
- 持有 5 至 10 分钟：约 −1%。
- 持有到结算：train +5.3%、test +2.0%，CI 都跨 0。

| 假设 | 结论 |
|---|---|
| H1 赛前 1X2 价格对照博彩公司公允价（偏差、价值规则） | 不可利用 |
| H1b Polymarket 赛前是否滞后于博彩公司 | 不可利用 |
| H2 盘中进球模型对照市场（按状态校准、规则） | 不可利用 |
| H3 进球和红牌后的过度或不足反应 | 不可利用；按跳变锚定的"优势"是 VAR 幸存者偏差 |
| H4 O/U 2.5 和 BTTS（赛前、盘中时间衰减） | 不可利用；分钟价上的优势在真实成交上消失 |
| H5 其他（1X2 三边套利、停盘后陈旧价、上线初期价格、主客队对调） | 无法下结论，倾向不可利用：数据不足以干净检验 |

## 1. 数据、切分、成本与统计口径

**样本**
- 比赛：2,200 场 `analysis_ready`（已排除重复事件、延期和中止的比赛）。
- 切分：train 为开球早于 2026-02-01，共 1,022 场；test 为其后的 1,178 场，含 2025-26 赛季 726 场和 2026-27 赛季 452 场。
- 只有 1 场的模型 λ 拟合失败并被剔除：`bun-bay-uni-2026-09-18`。

**价格来源**
- 1X2 用 `data/soccer_data/trades.parquet` 里的真实成交。
- O/U 2.5 和 BTTS：
  - 先用分钟价做分析。
  - 再自己用 Data API v2 抓了 3,555 个市场从开球前 2 小时起的 taker 成交，共 1,077,790 笔：0 错误，约 10 分钟，最多 4 个并发请求，只读。

**博彩公司基准（football-data 数据）**
- Pinnacle 收盘赔率只到 2026-01-15，所以只能用于 train。
- 可以同时部署在两期的基准我记为 `bfx`：优先用 Betfair 交易所收盘价，按比例去 vig（overround 中位数 1.005，约 95% 的比赛有）；没有时退回市场平均收盘价，用 power 法去 vig。

**执行价**
- 一律取决策时刻之后的第一笔 taker 成交：
  - 买 YES：取"taker 获得 YES 敞口"那类成交的价格，相当于 ask。
  - 买 NO：成本取 1 减去"taker 获得 NO 敞口"那类成交的价格，相当于 1 − bid。
  - 平仓对称处理。
- 盘中决策加 2 秒延迟；入场成交必须出现在决策后 60 秒内，平仓成交在 180 秒内。
- 每笔 10 USDC。
- 买卖两腿都扣费；持有到结算的一腿不扣费。
- 用进场附近的成交量检查深度。

**统计**
- 参数只在 train 期选；test 期结果原样报告。
- ROI 的 95% CI 用按比赛聚类的 bootstrap（1,000 到 2,000 次重抽）。

## 2. H1：赛前定价

### 2.1 开球前 5 分钟的准确度（三项同场归一）

| 时期 | 比赛数 | Brier: PM mid / Pinnacle 收盘 / Betfair 收盘 / 市场平均收盘 | log loss（同顺序） |
|---|---:|---|---|
| train | 895 | 0.5713 / 0.5724 / 0.5712 / 0.5707 | 0.9600 / 0.9626 / 0.9604 / 0.9596 |
| test | 1,067 | 0.5792 / – / 0.5791 / 0.5792 | 0.9749 / – / 0.9747 / 0.9748 |

- PM 和 Betfair 收盘、市场平均收盘一样准。
- 这份数据里的 Pinnacle 收盘反而最差。
- 按角色看，PM 成交 mid 比 Betfair 公允价略高：
  - train：主/平/客 +0.30 / +0.17 / +0.33c。
  - test：+0.19 / +0.10 / +0.16c。
- 原因是成交多为买方主动，三项 mid 相加为 1.0086（train）/ 1.0042（test）。
- 平均绝对偏差 0.5 至 0.6c，成交价差中位数 1c。
- 各联赛的偏差都在 0 到 0.4c。
- 各价格档位都没有超过 ±1c 的热门-冷门偏差或平局偏差（`h1_buckets.csv`）。

- 在 PM 比 Pinnacle 便宜时下注，会显著亏钱：分歧时 PM 是对的。

### 2.3 PM 是否滞后于博彩公司

1. **"开盘"快照不是同期信息。** PM 价格路径与 football-data"开盘"快照最接近的时点在开球前 1 到 3 天（平均绝对误差 0.85c；开球时为 1.7c）。所以在 T−6h，这个快照已是陈旧信息。
2. **开盘信号不预测 PM 之后的漂移。** 回归"PM 从 T−x 到 T−5m 的变动"对"开盘公允价减 PM(T−x)"：
   - x ≤ 6h 时，斜率为 0.01 到 0.14，相关 ≤ 0.13。
   - 只有 T−24h 时斜率达到 0.72 / 0.59，但这时开盘快照可能还没公开，属于前视。
3. **PM 跑在开盘快照前面。** 在 T−1h，PM 离 Betfair 收盘的平均距离是 1.0c，开盘快照是 1.6 至 1.7c。
4. **收敛交易全部不行。** 在 T−x 进场、T−5m 用成交价平仓：
   - 237 行里 98% 为负，最好的是 train 期 12 笔、+2.9%。
   - 典型值为每笔 −5% 到 −10%（价差加两次手续费）。
   - 持有到结算的版本：train 和 test 都没有任何变体 CI > 0。

**结论：不可利用。** 本数据集里赛前价格已和 Betfair 收盘一样有效。

## 3. H2：盘中模型对照市场

**模型**
- 结构：用净胜球做 Markov 链。
- 进球时间分布：用 2,812 个 train 期进球估计（42.7% 在上半场）。
- 比分和红牌效应：在 train 上用 Poisson GLM 估计倍数（`h2_model_glm.txt`）：

  | 状态 | 进球率倍数 |
  |---|---|
  | 领先 1 球 | ×0.77 |
  | 领先 ≥ 2 球 | ×0.72 |
  | 落后 | ×0.94 |
  | 本方少一人 | ×0.48 |
  | 对方少一人 | ×1.66 |

- 赛前 λ：逐场求解，使模型复现 `bfx` 收盘 1X2。

**快照**
- 比赛进行中每 60 秒一个，共 651k 行。
- 比分状态用"按成交定位的事件时间 ≤ t"的事件。
- 只剔除"距上一个事件不足 120 秒"的快照，从不用未来事件筛样。

**准确度。** 从第 30 分钟起，市场的 log loss 在每个时段、两期都优于模型。例：60 至 70 分钟，train 0.4325 对 0.4383，test 0.4439 对 0.4511。30 分钟前两者相同（差 ±0.0015）。约 100 个状态格子里，train 最大 |z| 为 2.28，与偶然一致。

**规则（每场每市场只取第一个信号，持有到结算）：**

| 规则 | train | test |
|---|---|---|
| 模型边际 ≥ 3c，买 YES | 2,120 笔，**−12.3% [−18.8, −6.0]** | 2,675 笔，−4.5% [−9.6, +0.9] |
| 模型边际 ≥ 3c，买 NO | 2,112 笔，−2.6% [−7.1, +2.4] | 2,692 笔，+0.2% [−4.0, +5.1] |
| 模型边际 ≥ 8c，买 NO | 1,355 笔，−0.4% | 1,624 笔，+2.7% [−3.0, +8.4] |
| 第 70 分钟后买当前比分对应结果 | 1,132 笔，**−5.4% [−8.8, −1.8]** | 1,357 笔，−0.3% [−3.7, +3.2] |
| 第 80 分钟后买当前比分对应结果 | 924 笔，**−7.2% [−10.8, −3.6]** | 1,126 笔，−1.0% [−4.0, +2.3] |
| 第 80 分钟后反着买当前比分（买 NO） | 953 笔，+11.6% [−3.2, +28.0] | 1,130 笔，**−16.4% [−25.9, −7.0]** |

| 热门球队落后 1 球（45 至 70 分钟），买 NO | 241 笔，+2.3% [−3.4, +7.7] | 282 笔，+2.9% [−2.6, +8.7] |
| 热门球队落后 1 球（70 至 85 分钟），买 YES | 163 笔，+20.6% | 209 笔，−14.9% |

- 用真实成交复测后，"末段买当前比分"的结论与上一个项目一致：train 显著为负，test 约为 0。
- "热门落后时买 NO"在两期都略为正，但它只是 72 个变体之一，CI 都跨 0，只能算待观察的假设。

**结论：不可利用。** 市场优于我的模型；模型和市场的偏差主要是模型误差。

## 5. H4：O/U 2.5 和 BTTS

**赛前。** O/U 2.5 方面，PM 与 Betfair 收盘的平均差距为 0.53c（train）/ 0.48c（test）。Brier：train 0.2497 对 0.2485（603 场），test 0.2336 对 0.2334。BTTS 方面，PM 与我的 Poisson 公允价相差 2 到 4c，准确度相当。价值规则（假设半价差 1c）：
- 用 Pinnacle 时几乎不触发（23 笔）。
- BTTS d=0：train +3.0%（355 笔），test −8.2% [−17.1, +0.3]。

**盘中，分钟价加假设的 1c 半价差：**
- 模型 log loss 比 PM 分钟价好：O/U 在 train 是 0.5386 对 0.5632，test 是 0.5365 对 0.5396；BTTS 在 train 是 0.5912 对 0.6290。

## 6. H5：其他

**1X2 三边套利**
- T−5m 时，三个 YES 首笔 ask 之和中位数为 1.016。按非同时成交估计，扣费后三边全买 YES 能盈利的场次为 0.75%，三边全买 NO 为 0.84%。
- 盘中用"120 秒内最后成交"估计，比例为 1.9% 和 5.7%，但这些成交不同时，多半是陈旧价造成的假象。
- 要验证需要订单簿数据。结论：无法下结论，倾向不可利用。

**停盘后陈旧价**
- 65 场盘中静默 ≥ 15 分钟（中位数 20 分钟）。
- 其中 24 场在重开时和 5 分钟后都有价格：重开后 5 分钟价格变动中位数 4.3c，最大 30c（例：`fl1-lor-tou-2025-11-09` 从 0.32 到 0.62）。
- 但重开第一分钟通常只有 1 到 3 笔成交，几乎没有深度，样本也太少。结论：无法下结论。

**主客队对调**：只有 1 场，无策略意义。

**上线初期价格**：市场约在开球前 13.4 天上线。T−7d 的 PM 价格离收盘约 2.8c，但那时没有同期博彩赔率，无法在不前视的情况下检验。

这么多变体下，train 期出现一些"赢家"是必然的。所有没有结构性解释的赢家，到 test 期都反号或消失了。唯一两期都显著的 H3 规则，事后查明是前视造成的。

## 8. 前视和注意事项

- **VAR 幸存者偏差（最关键）。** 用价格跳变当事件时间时，样本只包含最终有效的进球。任何"进球后 X 秒入场"的回测，都必须包含被取消的进球，或者等官方确认后再入场。
- **收盘赔率当作 T−5m 和 T−1m 的公允价**，有不超过 5 分钟的前视。因为本来就没有优势，这不影响结论。
- **football-data 的"开盘"快照**实际在开球前 1 到 3 天采集。T−24h 的检验可能用到了当时尚未公开的赔率。
- **分钟价不可成交**，而且在事件附近滞后。H4 是一个典型例子：分钟价上的 +10% 到 +25%，换成真实成交后变成 0 或负数。
- **"决策后第一笔成交"是别人的成交**，可能被抢走。H3 我用了 15 秒内最差成交价做稳健性检验。
- 2026 年 4 月的 BUY 成交量已扣掉以股份支付的手续费，只轻微影响深度估计，不影响价格。
- 手续费在所有时期一律按 0.05 费率计算。
