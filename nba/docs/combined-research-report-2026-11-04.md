# Polymarket 足球和 NBA 比赛盘：有没有可执行的盈利策略？

自主研究报告。2026-11-04 13:16 由 the project owner 发起，17:30 完成。负责人：3bet（主 agent）。
全程只读研究：没有下单，没有碰钱包，也没有动 VPS 上的实盘 bot。

---

## 一、结论

**以我们现有的条件，在 Polymarket 的 NBA 和五大联赛足球比赛盘里，没有找到期望为正、又能实际执行的策略。**

- 一共测试了 5,000 多个规则变体。
  - 有些规则只在训练期赚钱，到没参与调参的测试期就失效或反过来亏钱。
  - 两期都显著为正的只有两类：一类要求在事件发生后 2–5 秒内成交，另一类要求挂单排在队列最前面（老做市商的位置）。这两样我们都做不到。
- 原因有三个：
  1. **赛前定价和最准的博彩公司一样准。**
     - NBA：Polymarket 开赛前 1 分钟的价格，与 DraftKings/ESPN 去掉抽水后的收盘价平均只差 1.1–1.3c。两者的 Brier 分数几乎相同：训练期 0.2067 对 0.2065，测试期 0.1772 对 0.1777。
     - 足球：Polymarket 与 Betfair 收盘价的 Brier 分数也一样：0.5735 对 0.5735，0.5794 对 0.5791。
  2. **手续费比剩下的定价偏差还大。** 吃单费按每股 0.05·p·(1−p) 收取：在 50c 附近每次成交约 1.25c/股，再加上半个价差，进出一次约 3.5c。
  3. **比赛中市场比我们能拿到的数据快。** 从 ESPN 记录一次得分到市场反应，中位延迟在 2024-25 赛季是 10 秒，2025-26 是 4 秒，2026-27 已经是 0 秒。足球进球时，在 ESPN 时间戳那一刻价格已经走完 22%，5 秒后走完约一半。
- **对现行实盘策略的含义：**
  - 用 2025-26 加本赛季共 793 笔回放现行入场规则：持有到结算 −5.8%（95% CI −14.3% ~ +3.0%）；加上现行止损止盈 −10.3%（−16.8% ~ −3.1%）。如果止损按 19c 成交（更接近我们 bot 的实际成交），是 −6.5%（−12.9% ~ +0.2%）。
  - 止损和止盈触发时的成交价本身是公允的：卖出后的胜率基本等于卖出价。所以这两条退出规则只是降低波动，每股多付约 1–2c 成本。
  - 前 6 个实盘日累计 −39.54u，与“没有优势”一致。

## 二、思考路径

不从现有策略出发，先问一个问题：在体育预测市场里，利润可能来自哪里？我列出 6 类来源，每类都设计了可证伪的检验。

| 利润来源 | 对应假设 | 由谁检验 |
|---|---|---|
| 1. 定价偏差（行为偏差） | 热门和冷门定价系统性偏离、平局偏差、热门球队溢价、背靠背和休息天数没被定价、季后赛效应 | nba_pre，soccer_strat |
| 2. 外部公允价 | Polymarket 偏离 Pinnacle、Betfair、DraftKings；赛前跟不上博彩公司的盘口变动 | nba_pre，soccer_strat |
| 3. 比赛中模型 | 用比分、时间、赛前实力推出胜率，与市场价比较；领先优势的回归；临近终场接近确定的盘口；连续得分后反应过度；暂停和中场时的漂移；大小分对比赛节奏的反应 | nba_live，soccer_strat |
| 4. 信息速度 | Kalshi 先动、Polymarket 跟进；得分或进球后抢先成交 | xmarket，micro，nba_live，soccer_strat |
| 5. 结构性套利 | 同一市场 YES+NO 价格之和偏离 1；让分阶梯不单调；胜负盘和让分盘价格矛盾；足球胜平负三项之和偏离 1 | xmarket |
| 6. 提供流动性 | 挂单做市赚价差加返佣；哪些吃单方是聪明钱、能否跟单 | micro |

另加一项：用大样本重新检验现行实盘规则的入场和退出（nba_pre、nba_live）。

## 三、验证方法

- **训练和测试分开。**
  - NBA：训练期 = 2024-25 全季加上 2025-26 赛季到 2026-01-31；测试期 = 2026-02-01 至 2026-11-02。
  - 足球：训练期 = 2025-26 赛季到 2026-01-31；测试期为之后至今。
  - 参数只在训练期选，测试期结果原样报告。
- **成本按今天的标准算。** 所有时期都按 0.05 费率扣吃单费，不管当时实际收不收；同时给出不扣费的毛收益。
- **只用能成交的价格。**
  - 进出场都用真实的吃单成交价或盘口价，不用分钟历史价。分钟价在事件附近滞后，按它算出来的是幻觉收益。
  - 比赛中的信号至少延迟 2–15 秒后才入场，模拟 bot 的轮询延迟和 ESPN 数据的延迟。
- **统计标准。**
  - 95% 置信区间用按场次聚类的 bootstrap。
  - 分赛季、分月份看结果是否稳定。
  - 记录每类试过多少个变体，扣除多重比较的偶然性。
- **主 agent 验收。** 每个子 agent 交来的关键结论，我都用另写的代码、尽量换一条数据路径独立重算（第七节）。

## 七、主 agent 验收

| 结论 | 我的复核方式 | 结果 |

| 两套数据集完整 | 随机抽 6 个足球盘口、5 场 NBA，重新读 Gamma | 成交量和官方一致（足球有一笔差 3%，是已记录的 2026 年 4 月扣费问题）；结算 11/11 一致 |

| Data API 成交时间戳晚约 4 秒 | 用 bot 自己 108 笔成交的交易哈希对时 | 中位 4 秒，范围 2–7 秒 |
| 盘内无套利 | 直接用 10 秒盘口和足球盘口重算三项和、两边之和 | NBA 卖价和 <1 只有 1/42,554 次；足球赛前卖价和最低 1.00 |
| 足球赛前和 Betfair 一样准 | 改用分钟价，去抽水方法也换一种 | Brier 0.5735 对 0.5735；Polymarket 与博彩公司平均差 0.35–0.85c |
| NBA 赛前和博彩公司一样准 | 用分钟价对比 ESPN 收盘去抽水价 | 训练期 0.2067 对 0.2065，测试期 0.1772 对 0.1777 |
| 现行规则回放为负 | 重新汇总 793 笔，并抽 6 笔到 Gamma 核对结算 | 持有 −5.8%，现行退出 −10.3%，结算 6/6 一致 |
| 止损和止盈卖在公允价 | 另写代码：用 ESPN 节次时间加原始成交 | 卖出比持有每股少 1–2c，各赛季 CI 都跨 0 |

**验收中发现并纠正的错误：**
1. **soccer_strat 自己查出 VAR 幸存者偏差。** “进球后跟进”的利润来自只统计了有效进球。改成等进球确认后再入场，利润消失。
2. **按分钟价算的收益是幻觉。** 例如足球大小分：分钟价 +10% ~ +25%，按真实成交是 0 或负。之前的足球研究踩过同样的坑。
3. **成交时间戳比实际成交晚约 4 秒。** 不校正的话，会错误地看出 Kalshi 领先 4 秒。
4. **我自己的复核脚本出过错。** pandas 3 的时间精度是微秒，我按纳秒换算，节次时间小了 1000 倍，导致第一次复核止损和止盈时，“下半场”的筛选没有生效。修正后结论方向不变，但幅度从我之前消息里说的每股 1.5–3c 改为 1–2c。

## 八、对现行 NBA 实盘的含义和建议

- **入场规则：** 在 793 笔回放里，选中的 token 胜率 40.1%，平均买入价 41.6c，低于买入价隐含的胜率。持有到结算 −5.8%，CI 跨 0，看不出有优势。
  - 注意：2025-26 赛季每场只有 1–3 条让分盘，和现在每场 33 条不完全可比。但在 2026-27 的 107 场里，持有也是 −20%（CI −43.9% ~ +4.5%）。
- **退出规则：** 止损和止盈触发时的价格是公允的，卖出只是多付费用和价差。在回放里，止损是亏损的主要来源：451 次止损平均亏 80.5%。
- **建议（由 the project owner 决定，我没有改任何东西）：**
  1. **停止或暂停 NBA 实盘。** 按现在的证据，每投 10u 期望约 −0.6 到 −1u。
  2. US-11/04 这一天已经布置好（北京时间 11/05 08:00 开始，14 场、每场 10u，最多约 140u）。按回放估算，期望亏 8–14u。可以选：
     - 开赛前取消；
     - 照常跑，当作最后一个样本；
     - 改成持有到结算。仍然是负期望，只是少付退出成本。
  3. 如果以后还想做实盘研究，建议把每场降到 1–2u，只为收集数据，并去掉止损和止盈。

## 九、如果还要继续：剩下的方向（优先级都低，各带停止条件）

1. **测 ESPN 数据比电视晚多少。** 明天比赛时每秒轮询一次，记录 ESPN 时间戳与我们拿到数据的时间差。只有延迟不超过 2 秒，“最后 5 分钟得分后跟进”才值得小额前瞻测试。考虑到本赛季市场相对 ESPN 已经是 0 秒延迟，预计没希望。
2. **季后赛冷门**（+16.7%，CI 跨 0）：只能等 2027 年季后赛积累样本再看。
3. **流动性更差、定价更粗的市场**（大学篮球、小联赛、其他平台）：这次没测。按已有调研，这些市场成交量比 NBA 小一两个数量级。
4. **不建议再投入的方向：** Kalshi 领先、盘内套利、挂单做市、比赛中模型、赛前价值投注。证据已经足够明确。
