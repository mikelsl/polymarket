# Polymarket NBA and football research

This public snapshot records research process, selected result tables, and a limited historical NBA live-trading summary. No profitable executable strategy was established by the studies. The football track was research-only and placed no live trades.

- NBA: see nba/README.md for seven US game days (2026-10-28 through 2026-11-04), curated daily P&L, research reports and selected analysis outputs.
- Football (soccer): see football/README.md for five major leagues, the initial and expanded cohorts, rule testing and market-book coverage. No football live P&L exists.
- docs/DATA_POLICY.md explains exclusions, provenance and reproducibility limits.

Results are historical and not investment advice. A backtest is not live profit. Source third-party market/sports APIs are attributed in the reports. No license file is included; public visibility does not itself grant reuse rights.
